# 📩 Компонент `Subscription`

Адаптивный формы подписки с валидацией email, модальным окном подтверждения и отправкой данных на тестовый API.

---

## ✨ Возможности

- 📧 Валидация email (проверка формата и обязательности).
- 🔄 Отправка данных на **тестовый API**: [`https://reqres.in/api/users`](https://reqres.in/).
- ✅ Модальное окно при успешной подписке.
- ❌ Отображение ошибок при неверном вводе или сбое запроса.
- 🎨 Оформление по **БЭМ** через `styled-components`.
- 📱 Адаптивная верстка.

---

## 🛠 Используемые технологии

- **React**
- **TypeScript**
- **React Hook Form** — управление формой и валидацией.
- **Axios** — HTTP-запросы.
- **styled-components** — стилизация.
