# 📩 Компонент `SubscriptionForm`

`SubscriptionForm` — это адаптивный React-компонент для подписки на рассылку с валидацией email, написанный с использованием **React Hook Form**, **Axios** и **styled-components**.

## ✨ Возможности

- 📧 Проверка корректности email-адреса (валидация на стороне клиента).
- 🔄 Отправка данных на сервер через `axios.post('/api/subscribe')`.
- ✅ Сообщение об успешной подписке.
- ❌ Отображение ошибок при неверном вводе или сбое запроса.
- 📱 Полностью адаптивная верстка с поддержкой **mobile-first**.
- 🎨 Оформление по методологии **БЭМ** с использованием `styled-components`.

## 🛠 Технологии

- **React**
- **TypeScript**
- **React Hook Form** — управление формой и валидацией.
- **Axios** — отправка запросов на сервер.
- **styled-components** — стилизация компонентов.

## 🚀 Использование

1. Установите зависимости:
   ```bash
   npm install react-hook-form axios styled-components
   ```
